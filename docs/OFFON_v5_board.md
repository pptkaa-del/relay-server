# Плата «OFFON reley ver_5_1» (ESP32 + SIM7670)

Назначение выводов восстановлено по разводке `OFFON_reley_ver_5_1.lay6` (Sprint-Layout 6):
подписи на шелкографии, площадки модуля ESP32-WROOM-32 и трассировка меди обоих слоёв.

Прошивки:
* `firmware/OFFON_v5_esp32` — основной контроллер (ESP32), протокол v3;
* `firmware/OFFON_v5_watchdog_attiny85` — внешний сторожевой таймер (ATtiny85).

## ESP32-WROOM-32

| GPIO | Назначение | Уровень |
|---|---|---|
| IO26 | ключ катушки реле 1 | HIGH — катушка под током |
| IO25 | ключ катушки реле 2 | HIGH — катушка под током |
| IO33 | ключ катушки реле 3 | HIGH — катушка под током |
| IO32 | ключ катушки реле 4 | HIGH — катушка под током |
| IO23 | контроль выхода 1 (выпрямитель 230 В → оптрон, светодиод 1) | HIGH — напряжение есть (импульсы 100 Гц) |
| IO22 | контроль выхода 2 (оптрон, светодиод 2) | HIGH — напряжение есть |
| IO21 | контроль выхода 3 (оптрон, светодиод 3) | HIGH — напряжение есть |
| IO19 | контроль выхода 4 (оптрон, светодиод 4) | HIGH — напряжение есть |
| IO18 | замок: оптрон → MOSFET → клеммы «+ Замок −» | HIGH — замок под напряжением |
| IO27 | геркон (между 3V3 и входом) | HIGH — геркон замкнут (дверь закрыта) |
| IO34 | делитель напряжения питания/АКБ (АЦП) | мВ, калибровка на сервере |
| IO14 | импульсы WATCHDOG → транзистор → PB2 ATtiny85 | импульс HIGH 20 мс раз в секунду |
| IO4 | RX ← «tx» модуля SIM7670 | UART 115200 |
| IO2 | TX → «rx» модуля SIM7670 | UART 115200 |
| IO16, IO17 | разъём «add port» | не используются |
| IO0 | кнопка Download, разъём Prog | — |
| EN | кнопка Reset, разъём Prog, транзистор от PB4 ATtiny85 | — |
| TXD0, RXD0 | разъём Prog (txd, rxd) | — |

Реле подключены к клеммам контактами **COM + NC**: нагрузка включена, когда катушка **обесточена**.
Поэтому «включить» = GPIO LOW, «выключить» = GPIO HIGH, а при старте и пропадании питания контроллера
все выходы включены. Если реле будут подключены иначе — `RELAY_COIL_ON_MEANS_OUTPUT_ON 1` в прошивке.

## ATtiny85 (внешний WATCHDOG)

| Вывод | Назначение |
|---|---|
| PB2 (7) | ← импульсы ESP32 (через транзистор: импульс = LOW) |
| PB4 (3) | → транзистор → EN ESP32 (HIGH = сброс ESP32) |
| PB3 (2) | → затвор MOSFET в «земле» ESP32, стабилизатора 3,3 В, модуля SIM7670 и оптронов (HIGH = питание есть) |
| VCC (8), GND (4) | постоянное питание 5 В, общая «земля» |
| PB0, PB1, RESET | не разведены |

Логика: нет импульсов 90 с → сброс ESP32 через EN; ещё 90 с → питание ESP32 и модема отключается на 10 с.

## Модуль SIM7670

Подключается разъёмом «+ pkey tx rx −»: «+» — 5 В, «−» — отключаемая «земля» (через MOSFET ATtiny85).
Вывод **pkey не разведён** к ESP32 — модуль должен включаться сам при подаче питания (у большинства
готовых плат SIM7670 PWRKEY подтянут на плате). Перезапуск модема — командой `AT+CRESET` (TinyGSM `restart()`)
или отключением питания через ATtiny85.

## Замечания по разводке ver_5_1

1. **Общий вывод выходных транзисторов четырёх оптронов контроля не подключён** ни к +3,3 В, ни к чему-либо ещё
   (дорожка соединяет только сами оптроны). Светодиоды контроля включены между линией GPIO и «землёй»,
   поэтому этот вывод должен идти на **+3,3 В** — иначе контроль выходов (и подтверждение команд) работать не будет.
   Прошивка рассчитана на подключение к +3,3 В. Проверьте плату или схему.
2. **IO2 — вывод начальной загрузки ESP32.** Для прошивки через Prog он должен быть LOW или не подключён.
   Если модуль SIM7670 подтягивает свой вход RX к питанию, прошивка ESP32 может не начаться
   («Wrong boot mode») — тогда прошивайте при снятом/обесточенном модуле.
3. Вход IO34 рассчитан на напряжение до ~3,1 В (аттенюатор 11 дБ). Делитель должен давать не больше этого
   при максимальном напряжении питания/АКБ.
